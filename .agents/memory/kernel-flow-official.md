# Flow officiel Kernel — Blueprint First

Document de référence validé. Remplace toutes les interprétations précédentes.

## Séquence principale

```
KERNEL BLUEPRINT → BANK TARGET → DEPTH NEED MATRIX → DOMAIN CYCLE
→ TAXONOMY → KEY_LEARNING_DIRECTION → KEY_STRUCTURE
→ PHASE 1 CRÉATION → PHASE 2 VALIDATION
→ PHASE 3 TRADUCTION → PHASE 4 VALIDATION TRADUCTION
→ PHASE 5 READY_BANK → GAMEPLAY
```

## Branche parallèle (quarantaine)

```
WARNING → PHASE 6 QUARANTAINE → PHASE 7 CORRECTION
→ PHASE 2 VALIDATION → PHASE 3 TRADUCTION → PHASE 4 VALIDATION TRADUCTION → READY_BANK
```

## Responsabilités officielles

| Étape | Responsabilité | Ce qu'elle ne fait PAS |
|---|---|---|
| KERNEL BLUEPRINT | Ouvrir le frame vide | Aucune décision métier |
| BANK TARGET | Stop si cible atteinte | Ne choisit pas le depth |
| DEPTH NEED MATRIX | Remplir le Depth ONLY | Ne choisit jamais le domaine |
| DOMAIN CYCLE | Remplir le Domaine ONLY | Ne choisit pas le depth |
| TAXONOMY | Compléter sous-domaine + sujet + idee_dominante | Ne décide pas la production globale |
| KEY_LEARNING_DIRECTION | Détecter doublons pédagogiques (hash subject+idee_dominante) | Ne crée pas |
| KEY_STRUCTURE | Garde structurel (hash depth+domain+sub_domain+subject+idee_dominante) | Ne crée pas, ne remplit pas |
| PHASE 1 | Remplir les 7 cognitifs | Ne modifie JAMAIS key/subject/idee_dominante |
| PHASE 2 | Valider chaque variant → VALIDATED_OK ou WARNING | |
| PHASE 3 | Traduire UNIQUEMENT les VALIDATED_OK | |
| PHASE 4 | Valider chaque traduction → VALIDATED_OK ou WARNING | |
| PHASE 5 READY_BANK | Recevoir uniquement VALIDATED_OK | |
| PHASE 6 QUARANTAINE | Contenir trace du WARNING | Ne bloque pas READY_BANK |
| PHASE 7 CORRECTION | Corriger les WARNING → retour PHASE 2 | |

## DEPTH NEED MATRIX — rotation officielle

```
Depth 2  × 8 domaines
Depth 4  × 8 domaines
Depth 6  × 8 domaines
Depth 7  × 8 domaines
Depth 8  × 8 domaines
Depth 9  × 8 domaines
Depth 10 × 8 domaines
→ recommence (peut sauter si besoin rempli)
```

## DOMAIN CYCLE — ordre officiel

```
Géographie → Histoire → Faune → Art → Sport → Cinéma → Cuisine → Général
```

## TAXONOMY — fallback sur doublon KEY_LEARNING_DIRECTION

```
Si subject+idee_dominante déjà utilisé :
  1. autre idee_dominante du même sujet
  2. autre sujet du même sous-domaine
  3. autre sous-domaine
```

## READY_BANK peut contenir

- noyau 7/7 validé
- ou uniquement les variants validés d'un noyau partiel

**Why:** Éviter de bloquer la production sur un variant problématique. Les VALIDATED_OK entrent en Ready_Bank immédiatement.
