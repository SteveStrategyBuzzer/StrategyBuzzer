## GAP-158-001

**Fichier:** `tests/Unit/QuestionBank/Taxonomy/SeededBankRotationBlueprintTest.php`

**Test concerné:** `test_bank_seeded_in_second_domain_is_reached_via_empty_transition`

**Symptôme:**
```
[KRP CONTAINMENT] peekNext() a retourné null pour depth=2, domain=geographie.
EMPTY loop désactivée jusqu'à spécification de 03_Taxonomy.
Blueprint supprimé. Aucune inférence DOMAIN_EXHAUSTED effectuée (DEC-087).
```

**Cause:**
Le test attend que l'orchestrateur passe automatiquement du domaine vide (`geographie`) au domaine suivant (`histoire`) via l'EMPTY loop. Cette boucle a été délibérément désactivée dans KRP v3.2 (DEC-087) jusqu'à ce que le contrat 03_Taxonomy soit spécifié (LOT C).

**Origine:**
Test écrit pour KRP v2 (EMPTY loop active). Non mis à jour lors du gel KRP v3.2.

**Ce qui a été fait dans #158:**
Le setUp de ce test a été complété avec les 4 colonnes KRP v3.2 manquantes (`depth_state`, `domain_states`, `pending_depth_exhausted_depth`, `domain_position`). Ce correctif a rendu visible l'erreur EMPTY loop qui était auparavant masquée par l'erreur schema.

**Ce qui ne peut PAS être fait sans autorisation:**
- Modifier les assertions du test (changer la logique métier)
- Implémenter l'EMPTY loop (LOT C interdit)
- Supprimer le test (nécessite autorisation explicite)

**Résolution requise:**
Soit : décision explicite de supprimer/skip le test (hors spec LOT C).
Soit : spec 03_Taxonomy + LOT C autorisé.

**Why:** DEC-087 désactive explicitement l'inférence DOMAIN_EXHAUSTED lors d'un peekNext null, jusqu'à spécification de 03_Taxonomy.

**Statut:** OUVERT — 1 test RED persistant dans SeededBankRotationBlueprintTest.
