Étape 3 — Corriger les 16 imports relatifs (1 action IA, puis un grep)

Prompt Replit AI

Remplace les imports relatifs vers packages/shared/... et packages/game-engine/... :

Dans apps/game-server/src/**/*.ts :

../../../../packages/shared/... -> @strategybuzzer/shared

../../../../packages/game-engine/... -> @strategybuzzer/game-engine

Dans packages/game-engine/src/*.ts :
