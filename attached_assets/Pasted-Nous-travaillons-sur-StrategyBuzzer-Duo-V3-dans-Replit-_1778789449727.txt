Objectif :
appliquer le micro patch SAFE du chrono sur la page Réponse Duo.

Fichier cible :
`resources/views/duo_answer.blade.php`

Problème confirmé :
dans `startTimer()`, la barre `timerBar` démarre visuellement à `width: 100%` via CSS, puis attend le premier tick `setInterval(250ms)` avant de recevoir sa vraie largeur.

Résultat actuel :

100% → vraie valeur restante.

Objectif du patch :
positionner immédiatement la barre à sa vraie valeur dès l’appel de `startTimer()`, avant le premier tick.

Contraintes :

* ne pas toucher Node
* ne pas toucher scoring
* ne pas toucher phases runtime
* ne pas toucher worker
* ne pas toucher guards IA
* ne pas toucher Question API
* ne pas ajouter de durée locale inventée
* ne pas modifier les appels `startTimer`
* ne pas modifier le `setInterval(250ms)`
* ne pas créer de nouveau timer

Patch attendu :
dans `startTimer()`, juste après le calcul de `answerWindowMs` et avant le `setInterval`, ajouter uniquement :

```js
// UX SAFE — positionne immédiatement la barre chrono à la vraie valeur
if (timerBar && answerWindowMs > 0) {
    var initPct = Math.max(0, Math.min(100, (remaining / answerWindowMs) * 100));
    timerBar.style.width = initPct + '%';
}
```
