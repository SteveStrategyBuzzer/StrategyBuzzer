3. Backfill readable_code

Format conseillé :
DOM-Dxx-TYPE-COG-SUFFIX

Exemples :

* HI-D03-Q-R-12B4C
* GE-D06-Q-T-A91FD
* SC-D05-V-RS-8C2E1

Codes :

* GE = Géographie
* HI = Histoire
* FA = Faune
* AR = Art
* SP = Sport
* CI = Cinéma
* CU = Cuisine
* SC = Science

Type :

* Q = QCM
* V = Vrai/Faux

Cognitif :

* R = recognition
* N = reasoning
* T = deceptive_trap
* RS = reasoning léger V/F

Important :
readable_code indexé, mais pas unique obligatoire.

4. Backfill minimal question_intent_key

Ne PAS laisser toute l’ancienne banque avec question_intent_key = NULL.

* remplir domain, sub_domain, difficulty_depth, concept_family si disponibles

6. Backfill hash_question / hash_answer

* hash_question = hash normalisé question_text

* funFact_score si possible, sinon nullable
