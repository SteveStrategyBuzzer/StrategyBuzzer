5. Consommation

Une question est consommée lorsque le joueur a vu :

Question
+
Bonne réponse
+
SV

Donc :

Question vue + résolution
=
consommée.

Question simplement envoyée :

≠ consommée.

Déconnexion avant résolution :

≠ consommée.
6. Consommation multi-joueurs

Duo / Ligue :

Si les participants actifs voient :

Question
+
Résolution

alors :

la question est consommée
pour tous les participants exposés.
7. MJ

MJ ne suit pas le matching collectif.

Le quiz est :

préparé indépendamment des joueurs.

Ensuite :

diffusé.

Puis :

consommation enregistrée
pour les joueurs exposés.

11. Buffer progressif

Le quiz n'est pas entièrement préparé d'avance.

La logique officielle est :

Solo
INTRO
↓
Node sélectionne et prépare Q1
↓
Q1 prête
↓
GAMEPLAY
↓
Node sélectionne/prépare/bufferise Q2...Qn
pendant que le joueur joue.
Duo / Ligue

Même logique.

READY / INTRO
↓
Node sélectionne et prépare Q1
↓
Q1 prête
↓
GAMEPLAY
↓
Node sélectionne/prépare/bufferise progressivement
Q2...Qn pendant la partie.

On utilise le temps naturel entre les questions.

MJ

MJ reste :

Quiz préconstruit
↓
Diffusion
