Corrige `resources/views/duo_answer.blade.php` pour les 5 bugs UI/feedback de la page Réponses Duo.

Contexte officiel :
- Flow Duo V3 = Q → R → R → S
- Tous les joueurs vont sur Réponses
- 1er buzzer : +2 si bonne / -2 si mauvaise
- 2e buzzer : +1 si bonne / -2 si mauvaise
- non-buzzer : 0 si bonne / 0 si mauvaise
- Node reste l’unique autorité via didBuzz + buzzOrder
- La page Réponses affiche seulement, elle ne recalcule pas le score final

Bugs à corriger :
1. Supprimer tout popup/overlay texte de résultat du type “0 point”, “bonne réponse”, “mauvaise réponse”.
2. Le pointage affiché doit respecter Node :
   - afficher +2, +1 ou -2 quand `pointsEarned` est non zéro
   - ne rien afficher quand `pointsEarned === 0`
   - ne jamais afficher “0 point”.
3. La bannière/vitesse de buzz en bas ne doit pas rester toujours `0.00ms`.
   - Si joueur a buzzé : afficher le vrai temps de buzz si disponible.
   - Si aucun temps fiable n’est disponible : afficher “Buzz enregistré” ou “Vous avez buzzé”, mais jamais `0.00ms`.
   - Si non-buzzer : afficher clairement participation 0 point, sans faux temps.
4. Les sons bonne/mauvaise réponse doivent rejouer correctement dans `showResult()`.
   - Garder correctSound / incorrectSound
   - Avant `play()`, faire `currentTime = 0`
   - Catcher l’erreur sans casser le visuel.
5. Les réponses doivent changer visuellement :
   - choix du joueur correct : contour vert / classe `.correct`
   - choix du joueur incorrect : contour rouge / classe `.incorrect`
   - ne pas afficher de popup texte
   - ne pas retirer inutilement `.selected` avant d’appliquer `.correct` / `.incorrect`
   - le bouton choisi doit rester visuellement identifiable
