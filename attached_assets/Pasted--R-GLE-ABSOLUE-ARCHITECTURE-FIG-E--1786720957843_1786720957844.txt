==================================================
DIFFÉRENCE ENTRE CHOIX TECHNIQUE ET CHOIX ARCHITECTURAL
==================================================

CHOIX TECHNIQUE AUTORISÉ :

Exemple :
utiliser SELECT FOR UPDATE pour garantir l'atomicité déjà exigée.

Le résultat métier reste identique.
→ autorisé.

CHOIX ARCHITECTURAL INTERDIT :

Exemple :
ajouter un état RECOVERY_PENDING parce qu'un crash est difficile
à gérer.

Cela modifie le contrat.
→ interdit.

Autre exemple :

utiliser un DTO RotationResolution
pour transporter une sélection déjà définie
→ technique, autorisé.

Faire de RotationResolution une nouvelle source de vérité persistante
→ architectural, interdit sans décision.

==================================================

Un test ne peut jamais devenir une justification
pour modifier l'architecture.

- vérifier si le test représente une architecture SUPERSEDED ;

INTERDIT :

INTERDIT notamment :

retirer final d'une classe
uniquement parce que PHPUnit ne sait pas la mocker.
