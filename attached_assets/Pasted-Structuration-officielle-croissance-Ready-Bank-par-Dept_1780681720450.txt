Structuration officielle — croissance Ready_Bank par Depth.

Objectif :
structurer la croissance de la banque de questions en NOYAUX, pas seulement en questions.

Règles de base :

1 noyau =
- 1 sujet
- 1 idée dominante directrice
- 7 questions cognitives

Les 7 cognitifs :
- QCM Recognition
- QCM Reasoning
- QCM DeceptiveTrap
- TF Recognition True
- TF Recognition False
- TF Reasoning True
- TF Reasoning False

Le noyau sert à :
- produire les 7 variantes cognitives
- contrôler l’anti-répétition
- éviter les doublons pédagogiques
- gérer KEY_STRUCTURE et KEY_LEARNING_DIRECTION

Important :
un match moyen = 3 manches × 20 questions = 60 questions.

Donc la Ready_Bank doit raisonner en :
noyaux exploitables gameplay,
pas seulement en volume brut de questions.

──────────────────────────────
ANTI-REDONDANCE
──────────────────────────────

Par défaut :
- éviter de rejouer le même noyau dans une même manche
- éviter de rejouer le même noyau trop rapidement dans un même match
- éviter de rejouer le même noyau trop souvent dans l’historique joueur

Mais :
DeceptiveTrap peut être une exception contrôlée,
car il peut volontairement réutiliser le même sujet/idée dominante
sous un angle trompeur différent.

Condition :
- jamais même cognitif immédiatement
- jamais simple reformulation
- DeceptiveTrap doit changer réellement l’angle
- learning_direction contrôlé
- reconstruction différente ou suffisamment forte

Anti-répétition recommandé :
- question_id
- noyau_id
- KEY_LEARNING_DIRECTION
- DECEPTIVETRAP_SIGNATURE
- LEARNING_SIGNATURE

──────────────────────────────
DEPTH = QUESTION
PERSONNALITÉ = ADVERSAIRE
──────────────────────────────

Depth appartient aux questions.

Depth définit :
- complexité cognitive
- degré de connaissance requis
- vocabulaire
- raisonnement
- difficulté du DeceptiveTrap
- longueur potentielle de la question
- longueur maximum selon vitesse de lecture attendue

Personnalité adversaire appartient aux élèves/Boss :
- buzz %
- temps de buzz
- abstention
- précision
- radar par domaine
- style de jeu
- agressivité / prudence

Ne jamais mélanger :
Depth = question
Personnalité = adversaire

──────────────────────────────
SV
──────────────────────────────

SV =
grande qualité constante de l’explication pédagogique,
indépendamment du Depth,
mais toujours liée au cognitif.

Recognition :
→ explique le fait principal

Reasoning :
→ explique le mécanisme causal/logique

DeceptiveTrap :
→ explique le réflexe naturel
→ l’erreur intuitive
→ la correction
→ la reconstruction

TF Recognition :
→ explique pourquoi vrai/faux

TF Reasoning :
→ explique pourquoi le raisonnement est vrai/faux

Si SV vague, décoratif ou non lié au cognitif :
→ WARNING
→ sv_low_explanatory_quality ou sv_cognitive_mismatch
