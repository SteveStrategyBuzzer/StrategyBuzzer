RÔLE DE ROTATION

Rotation est le cerveau du système.

Rotation ne choisit pas une question.

Rotation choisit :

Depth qui détient des règles pédagogique et structurale pour les questions / réponses 

| ÉlémentContrôlé par le Depth  |                       |
| ----------------------------- | --------------------- |
| Difficulté globale            | Oui                   |
| Niveau de connaissance requis | Oui                   |
| Complexité cognitive          | Oui                   |
| Vocabulaire                   | Oui                   |
| Longueur acceptable question  | Oui                   |
| Longueur acceptable réponses  | Oui                   |
| Difficulté des traps          | Oui                   |
| Répartition des cognitifs     | Oui                   |
| Temps de lecture accepté      | Oui                   |
| Temps de réflexion accepté    | Oui                   |
| Types de sujets autorisés     | Partiellement         |
| Qualité SV                    | Non (toujours élevée) |


Domaine
↓
Sous-domaine
↓
Sujet
↓
Idée dominante directrice

Puis Rotation vérifie :

# KEY_STRUCTURE

Depth + Domaine + Sous-domaine + Sujet + Idée dominante

# KEY_LEARNING_DIRECTION

Sujet + Idée dominante

L'objectif est d'éviter les doublons pédagogiques.

Rotation doit couvrir l'espace pédagogique.

Rotation ne remplit pas une banque de questions.

──────────────────────────────

RÔLE DU NOYAU

Le noyau représente un apprentissage.

Un noyau n'est pas une question.

Un noyau représente :

Sujet
+
Idée dominante directrice

Exemple :

Sujet :
Photosynthèse

Idée dominante :
Les chloroplastes permettent la fixation du CO₂

Le noyau existe pour organiser cet apprentissage.

──────────────────────────────

RÔLE DES 7 STYLES

Les 7 styles ne sont pas 7 apprentissages.

Les 7 styles sont 7 observations du même apprentissage.

QCM Recognition
QCM Reasoning
QCM DeceptiveTrap

TF Recognition True
TF Recognition False

TF Reasoning True
TF Reasoning False

Ils partagent tous :

Sujet
+
Idée dominante

Ils ne doivent jamais dériver vers un autre apprentissage.
