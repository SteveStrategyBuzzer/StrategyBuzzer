# PATCH AUTORISÉ — UNIQUEMENT CES 5 CORRECTIONS

## 1. Corriger `rotation_identifier.dependencies`

Actuellement, il ne doit PAS déclarer :

```text
depth_slot produit
domain_slot produit
```

Remplacer par :

```php
'dependencies' => [],
```

Pourquoi :

Le contrat dit seulement que KernelRotationPlanner produit `depth_slot`, `domain_slot` et `rotation_identifier`.

Il ne dit pas que `rotation_identifier` est calculé à partir de `depth_slot` et `domain_slot`.

---

## 2. Corriger `dependency_graph`

Supprimer l’entrée :

```php
'rotation_identifier' => ['depth_slot', 'domain_slot'],
```

Remplacer par :

```php
'rotation_identifier' => [],
```

Pourquoi :

Cette dépendance n’est pas verrouillée.

Le Blueprint ne doit pas inventer une relation non décidée.

---

## 3. Corriger `kernel_code_builder`

Supprimer toute chaîne du type :

```text
KernelRotationPlanner(rotation_identifier) + Taxonomy(...) + KEY_STRUCTURE(...) + KLD(...)
```

Remplacer par une formulation non-exécutive :

```php
'kernel_code_builder' => 'Non défini dans Blueprint Phase 0 — sera conçu dans une brique ultérieure.',
```

Pourquoi :

La construction officielle du `kernel_code` n’est pas encore verrouillée.

---

## 4. Corriger `step_3_taxonomy`

Supprimer toute mention :

```text
TaxonomyReader via KernelRotationPlanner
```

Remplacer par :

```php
'step_3_taxonomy' => 'Taxonomy — responsabilité future non implémentée dans Blueprint Phase 0.',
```

Pourquoi :

On n’a pas défini qui orchestre Taxonomy.

---

## 5. Corriger `READY_BANK => Phase4`

Supprimer toute dépendance ou mention qui affirme :

```text
READY_BANK dépend de Phase4
```

Remplacer par une formulation non-spéculative :

```php
'READY_BANK' => [],
```

ou supprimer l’entrée si le graphe accepte l’absence d’entrée.

Pourquoi :

Phase4 n’est pas encore conçue officiellement.
