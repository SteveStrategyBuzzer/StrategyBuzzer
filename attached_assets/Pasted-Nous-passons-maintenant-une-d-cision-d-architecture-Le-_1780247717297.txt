1. NOYAU COMMUN OBLIGATOIRE
──────────────────────────────

Chaque question doit partir du même noyau commun :

- Domaine
- Sous-domaine
- Sujet
- Depth
- Langue de création : EN
- Contraintes gameplay

Le noyau commun ne contient PAS une question maître.

Le noyau commun ne contient PAS un answer_target comme point de départ.

Le noyau commun définit seulement le territoire de connaissance et les contraintes de création.

──────────────────────────────
2. COGNITIF CIBLE
──────────────────────────────

Le cognitif cible est l’instrument choisi dès le départ.

Les 7 cognitifs officiels sont :

- QCM_Recognition
- QCM_Reasoning
- QCM_DeceptiveTrap
- TF_Recognition_True
- TF_Recognition_False
- TF_Reasoning_True
- TF_Reasoning_False

Chaque cognitif doit naître indépendamment du sous domanine + du Sujet + Relations cognitives.

Aucun cognitif ne doit être dérivé d’un autre cognitif.

Aucun cognitif ne doit être dérivé d’une question déjà produite.

──────────────────────────────
3. CAPACITÉ MENTALE OBSERVÉE
──────────────────────────────

La capacité mentale observée répond à :

Quelle capacité du cerveau ce cognitif cible veut-il observer avec la forme QCM ou TF ?

Pour chaque cognitif :

QCM_Recognition :
- observer la reconnaissance directe
- observer la mémoire immédiate
- observer le rappel d’un fait sans raisonnement
- Observer une réponse à choix multiple

QCM_Reasoning :
- observer la compréhension
- observer l’application d’une logique
- observer une déduction courte
- Observer une réponse à choix multiple

QCM_DeceptiveTrap :
- observer la résistance au réflexe
- observer la correction d’une hypothèse implicite
- observer la capacité à ne pas suivre une intuition trompeuse
- Observer une réponse à choix multiple

TF_Recognition_True :
- observer la validation immédiate d’un fait vrai reconnu
- Observer un résultat vrai

TF_Recognition_False :
- observer la détection d’une erreur factuelle plausible
- Observer un résultat Faut

TF_Reasoning_True :
- observer la validation d’une relation logique correcte
- Observer un résultat vrai

TF_Reasoning_False :
- observer la détection d’une relation logique incorrecte mais plausible
- Observer un résultat faut

4. RELATION COGNITIVE
──────────────────────────────

La relation cognitive sert à faire naître le nœud cognitif à partir du mix :

Depth
+
Sous-domaine
+
Sujet
+
Cognitif cible
+
Capacité mentale observée

Relations cognitives à utiliser :

1. Quel / Quelle / Qui / Où / Quand / Combien
   → identification directe
   → surtout Recognition

2. Pourquoi
   → cause
   → Reasoning

3. Qu’est ce que / Qu’est qui …
   → Reasoning

4. Comment
   → mécanisme
   → Reasoning

5. Conséquence / effet / résultat / rôle
   → conséquence logique
   → Reasoning

6. Comparaison / lequel / laquelle
   → position comparative
   → Reasoning ou Trap selon le cas

7. Trap
   → hypothèse implicite
   → réflexe
   → correction
   → DeceptiveTrap

La relation cognitive ne doit pas être indépendante du cognitif.

Le cognitif cible limite les relations cognitives autorisées.

Exemples :

QCM_Recognition :
relations autorisées :
- Quel
- Quelle
- Qui
- Où
- Quand
- Combien

QCM_Reasoning :
relations autorisées :
- Pourquoi
- Comment
- Conséquence
- Effet
- Résultat
- Rôle
- Comparaison logique

QCM_DeceptiveTrap :
relations autorisées :
- Trap
- Hypothèse implicite
- Réflexe populaire
- Comparaison trompeuse
- Correction d’hypothèse

TF_Recognition_True :
relations autorisées :
- affirmation vraie directe
- reconnaissance de fait

TF_Recognition_False :
relations autorisées :
- affirmation fausse plausible
- erreur factuelle proche du vrai

TF_Reasoning_True :
relations autorisées :
- relation logique vraie
- cause vraie
- mécanisme vrai
- conséquence vraie

TF_Reasoning_False :
relations autorisées :
- relation logique fausse mais plausible

- fausse conséquence

──────────────────────────────
5. NŒUD COGNITIF
──────────────────────────────

Le nœud cognitif ne naît pas seulement de :
Depth
+
Sous-domaine
+
Sujet

Il naît de :

Sous-domaine
+
Sujet
+
Cognitif cible
+
Capacité mentale observée
+
Relation cognitive

Le nœud cognitif est la connaissance exacte sélectionnée pour mesurer la capacité mentale ciblée.

Exemple :

Sous-domaine : Capitales
Sujet : Paris

QCM_Recognition :
Relation : Quelle
Nœud cognitif :
France ↔ Paris

Question possible :
Quelle est la capitale de la France ?

Bonne réponse :
Paris

QCM_Reasoning :
Relation : Pourquoi
Nœud cognitif :
Capitale ↔ fonction politique / gouvernementale

Question possible :
Pourquoi Paris est-elle considérée comme la capitale politique de la France ?

Bonne réponse possible :
Parce qu’elle concentre les institutions du gouvernement.

QCM_DeceptiveTrap :
Relation : Trap
Nœud cognitif :
Capitale francophone
↓
Réflexe = Paris
↓
Correction = Kinshasa

Question possible :
Quelle est la plus grande capitale francophone du monde ?

Bonne réponse :
Kinshasa

Conclusion :

Même sous-domaine.
Même sujet.
Mais nœud différent selon le cognitif.

Donc le nœud cognitif doit être construit après le choix du cognitif cible.

──────────────────────────────
7. SPÉCIFICATION COGNITIVE
──────────────────────────────

La spécification cognitive est la recette obligatoire avant d’écrire la question.

Elle doit contenir ce qu’il faut construire pour provoquer le mécanisme cognitif.

QCM_Recognition :
- relation d’identification directe
- fait reconnu
- question directe
- réponses du même type
- aucune logique nécessaire
- aucun piège

QCM_Reasoning :
- relation logique choisie : pourquoi / comment / conséquence / comparaison
- principe logique utilisé
- contexte minimal
- déduction attendue
- mauvaise réponse = erreur de raisonnement plausible
- pas de mini-cours

QCM_DeceptiveTrap :
- hypothèse implicite
- primer dans le wording
- réponse réflexe attendue
- élément qui casse le réflexe
- reconstruction possible
- bonne réponse différente du réflexe
- natural_hypothesis_triggered doit être TRUE

TF_Recognition_True :
- affirmation vraie directe
- fait reconnu
- aucun lien logique complexe
- réponse TRUE

TF_Recognition_False :
- affirmation fausse plausible
- dimension fausse précise : date, lieu, personne, quantité, rôle, catégorie
- faux élément proche du vrai
- réponse FALSE

TF_Reasoning_True :
- relation logique vraie
- cause / mécanisme / conséquence
- lien vérifiable
- réponse TRUE

TF_Reasoning_False :
- relation logique fausse mais plausible
- faux lien logique
- mécanisme incorrect mais crédible
- réponse FALSE

──────────────────────────────
8. CONTRAINTES GAMEPLAY
──────────────────────────────

Les contraintes gameplay sont obligatoires.

La question doit être compatible avec StrategyBuzzer.

Inclure :

- lecture rapide
- compatibilité buzzer temps réel
- lisibilité mobile
- absence de mini-cours
- question courte selon le Depth
- réponses courtes
- choix lisibles rapidement
- pas de surcharge cognitive inutile
- pas de question scolaire lourde
- pas de formulation longue si Depth 3-5

Contraintes de lecture :

Depth 3-5 :
- question courte
- lecture humaine cible : 4 à 7 secondes maximum
- aucun paragraphe explicatif

Depth 6-8 :
- subtilité permise
- vocabulaire plus précis
- longueur maîtrisée
- toujours compatible gameplay buzzer

Noyau commun :

Domaine : Geography
Sous-domaine : Capitals
Sujet : Paris
Depth : 3-5
Langue création : EN
Contraintes gameplay : lecture rapide, QCM mobile, buzzer temps réel

QCM_Recognition :

Capacité mentale observée :
Reconnaissance directe.

Quelle.

France ↔ Paris.

Question :
What is the capital of France?

Réponses :

B. Lyon
C. Marseille
D. Bordeaux

Capacité mentale observée :
Compréhension de la fonction politique d’une capitale.

Pourquoi.

Capital ↔ seat of government.

Question :
Why is Paris France’s political capital?

Réponses :
A. It hosts the national government ✅
B. It has the most beaches
C. It is France’s oldest city
D. It has the largest airport

QCM_Reasoning — Comment :

Capacité mentale observée :
Compréhension du mécanisme de capitale.

Relation cognitive :
Comment.

Nœud cognitif :
City ↔ institutions ↔ capital.

Question :
How does a city function as a national capital?

Réponses :
A. By hosting key state institutions ✅
B. By having the most tourists
C. By being the largest city
D. By having the oldest buildings

QCM_Reasoning — Conséquence :

Capacité mentale observée :
Compréhension de l’effet d’une capitale.

Relation cognitive :
Conséquence / rôle.

Nœud cognitif :
Capital ↔ government concentration.

Question :
What is a main role of a national capital?

Réponses :
A. Hosting central government institutions ✅
B. Producing most national food
C. Controlling all private companies
D. Replacing all regional cities

QCM_DeceptiveTrap :

Capacité mentale observée :
Résistance au réflexe “francophone = Paris”.

Relation cognitive :
Trap.

Nœud cognitif :
French-speaking capital
↓
Reflex = Paris
↓
Correction = Kinshasa

Question :
What is the largest French-speaking capital by population?

Réponses :
A. Paris
B. Brussels
C. Kinshasa ✅
D. Ottawa

TF_Recognition_True :

Capacité mentale observée :
Validation d’un fait vrai reconnu.

Relation cognitive :
Affirmation vraie directe.

Nœud cognitif :
Paris ↔ capital of France.

Statement :
Paris is the capital of France.

Réponses :
A. True ✅
B. False

TF_Recognition_False :

Capacité mentale observée :
Détection d’une erreur factuelle plausible.

Affirmation fausse plausible.

Paris ↔ capital of Belgium = false.

Paris is the capital of Belgium.

Réponses :
A. True
B. False ✅

TF_Reasoning_True :

Capacité mentale observée :
Validation d’une relation logique vraie.

Relation cognitive :
Relation logique vraie.

Because Paris hosts France’s national government, it functions as the political capital.

A. True ✅

Capacité mentale observée :
Détection d’une relation logique fausse mais plausible.

Fausse cause / faux mécanisme.

Paris is capital because it is the most populated city = false logic.

Paris is France’s capital because it is the country’s most populated city.

Réponses :
A. True

──────────────────────────────

Avant qu'une question soit validée, le moteur doit exécuter un test de pureté cognitive.

Question à se poser :

"Si j'enlève le cognitif déclaré, dans quel cognitif cette question retombe-t-elle naturellement ?"

Exemples :

QCM_Reasoning :

Si la question retombe naturellement dans Recognition :

→ rejet

QCM_DeceptiveTrap :

Si la question retombe naturellement dans Recognition :

→ rejet

Si la question retombe naturellement dans Comparaison :

→ rejet

Si la question retombe naturellement dans Difficulté élevée :

→ rejet

TF_Reasoning_False :

Si l'erreur est seulement factuelle :

→ rejet

TF_Recognition_False :

Si l'erreur porte principalement sur une relation logique :

→ rejet

Objectif :

Garantir que chaque question mesure réellement le cognitif demandé.

Le moteur doit protéger la séparation des cognitifs dès la création du nœud cognitif et non uniquement lors de la validation finale.
